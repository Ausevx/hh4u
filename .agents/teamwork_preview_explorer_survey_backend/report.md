## Executive Summary

1. **Root-Cause of Zero Search Results for "vomiting" and "headache":**
   - In MongoDB Atlas, 184 `Level1Question` documents exist, and all 184 have 1536-dimensional embeddings.
   - However, **100% of the stored embeddings in MongoDB Atlas are synthetic pseudo-random vectors** generated by `MockEmbeddingService` (Mulberry32 PRNG with word-hash offsets). This was empirically proven: comparing the stored embedding of `"When does vomiting become dangerous?"` against `MockEmbeddingService.generateEmbedding()` yielded an **identical match (cosine similarity = 1.0000)**.
   - At runtime, the server runs with `GEMINI_API_KEY` present in `backend/.env`. `aiContainer.ts` dynamically instantiates `GeminiEmbeddingService`, calling Google Gemini's live `gemini-embedding-2` model (1536 dimensions).
   - When a user submits `"vomiting"` or `"headache"`, Gemini produces a true semantic embedding vector.
   - Comparing this genuine Gemini query vector against the synthetic Mulberry32 vectors in MongoDB Atlas yields a cosine similarity of only **0.0347** to **0.0833** across all 184 documents.
   - In Atlas `$vectorSearch`, scores are normalized via `(1 + cosine) / 2`, resulting in a top candidate score of ~**0.5417**.
   - Because the top score (0.5417) is significantly below the production threshold `MATCH_CONFIDENCE_THRESHOLD = 0.75`, `chatbotService.ts` classifies every query as low confidence (`matchConfident = false`), dispatches the query to `NeedsReviewQuery`, and responds with conversational fallback.
   - **Empirical Proof of Fix:** Generating live Gemini embeddings for both the query `"vomiting"` and the document `"When does vomiting become dangerous?"` produced a cosine similarity of **0.7871** ($> 0.75$), which matches with high confidence. For `"headache"`, live Gemini similarities with headache questions were **0.8088**, **0.8136**, and **0.7832** ($> 0.75$).

2. **MongoDB Atlas Vector Search Index Status:**
   - Index Name: `vector_index`
   - Collection: `level1questions` in database `hh4u`
   - Dimensions: `1536`, Similarity metric: `cosine`, Pre-filter path: `isActive`
   - Current Status: **`READY`** and **`queryable: true`** across all 3 Atlas replica set shards (`atlas-141f0j-shard-00-00`, `shard-00-01`, `shard-00-02`).
   - The index DDL in `vectorSearchService.ts` is correctly formed.

3. **Startup Verification & Embedding Backfill Mechanism:**
   - A non-blocking startup routine must run after `connectDB()` in `index.ts`.
   - The routine checks if `vector_index` exists (creating it asynchronously if missing).
   - It checks whether documents in `Level1Question` either lack embeddings (`null`, empty array) OR contain mock embeddings.
   - If missing/mock embeddings are detected and `GEMINI_API_KEY` is present, it triggers batch regeneration (chunks of 10 with a 300ms pause) so rate limits (429) are avoided.
   - An admin API trigger (`POST /api/admin/vector-sync`) allows manual re-indexing.

4. **Diagnostic Health Endpoint (`GET /api/admin/vector-status`):**
   - Returns a comprehensive JSON report containing:
     - `totalLevel1Questions` (184)
     - `questionsWithEmbeddings` (184)
     - `questionsWithGeminiEmbeddings` vs `questionsWithMockEmbeddings`
     - `atlasVectorIndex` (`exists: true`, `queryable: true`, `status: "READY"`, `name: "vector_index"`, `dimensions: 1536`)
     - `gemini` (`apiKeyConfigured: true`, `model: "gemini-embedding-2"`, `status: "CONFIGURED"`)
   - Mounted in `src/routes/adminRoutes.ts` prior to `adminAuthMiddleware` so health monitoring probes and automated test scripts can access it without a JWT token, while returning full diagnostic information.

5. **Bulk Upload Mode (`mode: 'append' | 'overwrite'`):**
   - Current: `adminKnowledgeBaseService.importKnowledgeBaseFromExcel` performs idempotent upserts only; it never deletes existing records.
   - Required: Read `mode` from multipart request body (`req.body.mode`) or query parameter (`req.query.mode`).
   - On `mode === 'overwrite'`, execute atomic deletion of existing `Level1Question`, `ConsultationQuery`, and `Answer` documents within a MongoDB session/transaction before inserting the new spreadsheet entries.
   - On `mode === 'append'` (default), retain current upsert behavior.

6. **Build and Test Verification:**
   - `npm run build` compiles with code 0 (`tsc`).
   - `npm test` requires `NODE_OPTIONS=--experimental-vm-modules` (pre-configured in `package.json`).
   - In `backend/tests/chatbot.gemini.test.ts`, R1, R2, and R3 pass cleanly. Candidate model names in `geminiLLMService.ts` include non-existent models (`gemini-3.6-flash`, `gemini-3.5-flash`), which trigger 503 errors and slow down retries; adding `gemini-2.5-flash` resolves this latency.

## 1. Deep Dive: Why "vomiting" and "headache" Return No Results

### 1.1 Database Document Inspection
Direct query to the live MongoDB Atlas cluster `ac-iwm5wyi-shard-00-01.iifejq3.mongodb.net`:

```bash
Database: hh4u
Collection: level1questions
Total Documents: 184
Documents with embedding field: 184 (100%)
Embedding Dimensions: 1536
```

Relevant questions in the database:
- `"When does vomiting become dangerous?"` (`_id: 6aadf944e8f4af9b78864282`)
- `"Why is my child vomiting repeatedly?"`
- `"Why am I getting headaches frequently?"`
- `"Why am I getting headaches so often?"`
- `"Why is my child complaining of headaches?"`
- `"Could stress be causing my headaches and stomach problems?"` (`_id: 6aadf93fe8f4af9b78864234`)

All corresponding `Answer` documents and `ConsultationQuery` records are present and correctly linked via `level1QuestionId`.

### 1.2 Mathematical Proof of Embedding Discrepancy

Inspection of document `When does vomiting become dangerous?`:
- First 5 vector elements stored in MongoDB:
  `[0.029849485819175358, -0.02669903931409762, 0.003550013622241936, -0.017146501394320404, -0.030649148460373195]`

Running `new MockEmbeddingService().generateEmbedding("When does vomiting become dangerous?")`:
- First 5 elements generated:
  `[0.029849485819175358, -0.02669903931409762, 0.003550013622241936, -0.017146501394320404, -0.030649148460373195]`
- **Cosine similarity between stored vector and Mock vector = 1.00000000.**

Running `ai.embedding.generateEmbedding("When does vomiting become dangerous?")` with live Gemini API (`gemini-embedding-2`):
- First 5 elements generated:
  `[0.043910403, -0.011590667, 0.025591316, -0.006245551, -0.0029847836]`
- **Cosine similarity between stored vector and live Gemini vector = 0.03474.**

### 1.3 What Happens During Query Execution

When the user queries `"vomiting"`:
1. `ChatbotController.handleQuery` calls `ChatbotService.processQuery({ text: 'vomiting', intent: 'direct_answer' })`.
2. `ai.llm.translateToEnglish("vomiting")` returns `"vomiting"`.
3. `ai.embedding.generateEmbedding("vomiting")` calls `GeminiEmbeddingService`, generating a **live Gemini 1536-dim vector**.
4. `searchLevel1Questions(queryEmbedding, 5)` runs MongoDB Atlas `$vectorSearch`:
   - Atlas compares the live Gemini vector against the stored Mock vectors.
   - Raw cosine similarity to all documents is between `0.03` and `0.08`.
   - Atlas computes `vectorSearchScore = (1 + cosine) / 2 = (1 + 0.0833) / 2 = 0.5417`.
5. The candidates returned are:
   - Rank 1: `"What should I do if my child misses a vaccination?"` (score: 0.5417)
   - Rank 2: `"What can I do for chronic back pain?"` (score: 0.5394)
   - Rank 3: `"Why do I have back pain after sitting for long hours?"` (score: 0.5349)
   - Rank 4: `"My child has diarrhea. What should I do?"` (score: 0.5346)
   - Rank 5: `"Do I need to check my thyroid, cholesterol and blood sugar regularly?"` (score: 0.5304)
6. `chatbotService.ts` checks:
   `const matchConfident = !!(topCandidate && topCandidate.score >= config.matchConfidenceThreshold);`
   Where `config.matchConfidenceThreshold = 0.75`.
   `0.5417 < 0.75` $\rightarrow$ `matchConfident = false`.
7. The chatbot branches to Step 8: creates a `NeedsReviewQuery` and falls back to generic conversational LLM response.

### 1.4 Verification with Homogeneous Gemini Embeddings

When both question and query use live Gemini embeddings:
- `"vomiting"` vs `"When does vomiting become dangerous?"` $\rightarrow$ **Cosine Similarity: 0.7871** (Atlas score: **0.8936**) $\rightarrow$ **CONFIDENT MATCH**
- `"headache"` vs `"Why am I getting headaches so often?"` $\rightarrow$ **Cosine Similarity: 0.8136** (Atlas score: **0.9068**) $\rightarrow$ **CONFIDENT MATCH**
- `"headache"` vs `"Why am I getting headaches frequently?"` $\rightarrow$ **Cosine Similarity: 0.8088** (Atlas score: **0.9044**) $\rightarrow$ **CONFIDENT MATCH**
- `"headache"` vs `"Why is my child complaining of headaches?"` $\rightarrow$ **Cosine Similarity: 0.7832** (Atlas score: **0.8916**) $\rightarrow$ **CONFIDENT MATCH**

**Conclusion:** Replacing the stored mock embeddings with real Gemini embeddings immediately fixes the chatbot search pipeline.

## 3. Plan: Startup Verification & Embedding Backfill

### 3.1 Backfill Strategy
A backfill function must be added to verify and update embeddings. It should support:
1. **Detecting Mock vs Real Embeddings:**
   - Sample the first active document.
   - Compute `MockEmbeddingService.generateEmbedding(sampleDoc.canonicalQuestionText)`.
   - If cosine similarity between the stored vector and the mock vector is $> 0.98$, the database contains mock embeddings and requires a full Gemini backfill.
2. **Detecting Missing Embeddings:**
   - Query: `{ $or: [{ embedding: { $exists: false } }, { embedding: { $size: 0 } }, { embedding: null }] }`.
3. **Safe Rate-Limited Batching:**
   - Firing 184 requests in parallel causes HTTP 429 quota exhaustion in Gemini API.
   - Batching in chunks of 10 with a 300ms pause between chunks completes in ~22 seconds without triggering 429 errors.

### 3.2 Implementation Blueprint: `vectorBackfillService.ts`

```typescript
import Level1Question from '../models/Level1Question';
import { getAIServices } from './ai/aiContainer';
import { MockEmbeddingService } from './ai/mock/mockEmbeddingService';
import { cosineSimilarity } from '../utils/vectorSimilarity';
import { checkVectorIndexStatus, createVectorSearchIndex, VECTOR_INDEX_NAME } from './vectorSearchService';

export interface BackfillProgress {
  totalQuestions: number;
  updatedQuestions: number;
  skippedQuestions: number;
  failedQuestions: number;
  durationMs: number;
}

/**
 * Checks if a stored embedding matches the deterministic mock generator.
 */
export async function isMockEmbedding(canonicalText: string, storedEmbedding?: number[]): Promise<boolean> {
  if (!storedEmbedding || storedEmbedding.length !== 1536) return false;
  const mockGen = new MockEmbeddingService();
  const mockVec = await mockGen.generateEmbedding(canonicalText);
  return cosineSimilarity(storedEmbedding, mockVec) > 0.98;
}

/**
 * Backfills Level1Questions missing Gemini embeddings or holding mock embeddings.
 */
export async function backfillLevel1Embeddings(options: {
  forceAll?: boolean;
  batchSize?: number;
  delayMs?: number;
} = {}): Promise<BackfillProgress> {
  const startTime = Date.now();
  const { forceAll = false, batchSize = 10, delayMs = 300 } = options;
  const ai = getAIServices();

  // If using Mock AI, skip backfill
  if (process.env.USE_MOCK_AI === 'true' || !process.env.GEMINI_API_KEY) {
    return { totalQuestions: 0, updatedQuestions: 0, skippedQuestions: 0, failedQuestions: 0, durationMs: 0 };
  }

  const allQuestions = await Level1Question.find({ isActive: true });
  const questionsToUpdate: typeof allQuestions = [];

  for (const q of allQuestions) {
    if (forceAll || !q.embedding || q.embedding.length !== 1536 || (await isMockEmbedding(q.canonicalQuestionText, q.embedding))) {
      questionsToUpdate.push(q);
    }
  }

  let updated = 0;
  let failed = 0;

  for (let i = 0; i < questionsToUpdate.length; i += batchSize) {
    const chunk = questionsToUpdate.slice(i, i + batchSize);
    await Promise.all(
      chunk.map(async (q) => {
        try {
          const emb = await ai.embedding.generateEmbedding(q.canonicalQuestionText);
          if (emb && emb.length === 1536) {
            await Level1Question.updateOne({ _id: q._id }, { $set: { embedding: emb } });
            updated++;
          }
        } catch (err) {
          console.error(`Failed embedding for "${q.canonicalQuestionText}":`, err);
          failed++;
        }
      })
    );
    if (i + batchSize < questionsToUpdate.length) {
      await new Promise((r) => setTimeout(r, delayMs));
    }
  }

  return {
    totalQuestions: allQuestions.length,
    updatedQuestions: updated,
    skippedQuestions: allQuestions.length - questionsToUpdate.length,
    failedQuestions: failed,
    durationMs: Date.now() - startTime,
  };
}

/**
 * Startup hook executed after database connection.
 */
export async function verifyAndInitializeVectorPipeline(): Promise<void> {
  try {
    const indexStatus = await checkVectorIndexStatus(VECTOR_INDEX_NAME);
    if (!indexStatus.exists) {
      console.log(`[VectorPipeline] Index "${VECTOR_INDEX_NAME}" not found. Creating...`);
      await createVectorSearchIndex({ waitForReady: false });
    }
    // Asynchronous backfill so server startup is non-blocking
    backfillLevel1Embeddings().then((res) => {
      if (res.updatedQuestions > 0) {
        console.log(`[VectorPipeline] Backfilled ${res.updatedQuestions} questions in ${res.durationMs}ms`);
      }
    }).catch((err) => {
      console.warn('[VectorPipeline] Background backfill warning:', err.message);
    });
  } catch (err: any) {
    console.warn('[VectorPipeline] Startup verification warning:', err.message);
  }
}
```

## 5. Plan: Bulk Upload Append vs Overwrite Mode

### 5.1 Architecture & Flow

```
[BulkUploadModal.tsx]
       |
       | (multipart/form-data: file=.xlsx, mode="append"|"overwrite")
       v
[POST /api/admin/knowledge-base/import]
       |
       | req.body.mode || req.query.mode
       v
[adminKnowledgeBaseController.importExcel]
       |
       | importKnowledgeBaseFromExcel(buffer, mode)
       v
[adminKnowledgeBaseService]
       |
       +---> If mode === 'overwrite':
       |        await Level1Question.deleteMany({}, opts);
       |        await ConsultationQuery.deleteMany({}, opts);
       |        await Answer.deleteMany({}, opts);
       |
       +---> Parse Excel, Generate Embeddings, Upsert/Insert Rows
```

### 5.2 Implementation Details

1. **Controller (`adminKnowledgeBaseController.ts`):**
   ```typescript
   export const importExcel = async (req: Request, res: Response): Promise<void> => {
     try {
       if (!req.file || !req.file.buffer || req.file.buffer.length === 0) {
         res.status(400).json({ success: false, message: 'No file uploaded' });
         return;
       }

       const rawMode = (req.body?.mode || req.query?.mode || 'append').toString().toLowerCase();
       const mode: 'append' | 'overwrite' = rawMode === 'overwrite' ? 'overwrite' : 'append';

       const result = await adminKnowledgeBaseService.importKnowledgeBaseFromExcel(
         req.file.buffer,
         mode
       );

       res.status(200).json({
         success: true,
         mode,
         counts: result.counts,
       });
     } catch (err: any) {
       // Error mapping (ExcelValidationError -> 400, etc.)
     }
   };
   ```

2. **Service (`adminKnowledgeBaseService.ts`):**
   ```typescript
   public async importKnowledgeBaseFromExcel(
     buffer: Buffer,
     mode: 'append' | 'overwrite' = 'append'
   ): Promise<KnowledgeBaseImportResult & { mode: string }> {
     // 1. Validate & parse Excel buffer
     const parsed = await parseExcelBuffer(buffer);

     // 2. Generate embeddings in chunks of 10 to avoid Gemini 429
     const ai = getAIServices();
     const questionTexts = parsed.level1Questions.map((q) => q.canonicalQuestionText);
     const embeddings: number[][] = [];
     for (let i = 0; i < questionTexts.length; i += 10) {
       const chunk = questionTexts.slice(i, i + 10);
       const chunkEmbeddings = await Promise.all(chunk.map((t) => ai.embedding.generateEmbedding(t)));
       embeddings.push(...chunkEmbeddings);
     }

     // 3. Persist within MongoDB transaction
     return this.executeWithTransaction(async (session) => {
       const opts = session ? { session } : {};

       // OVERWRITE MODE: Clean slate
       if (mode === 'overwrite') {
         await Promise.all([
           Level1Question.deleteMany({}, opts),
           ConsultationQuery.deleteMany({}, opts),
           Answer.deleteMany({}, opts),
         ]);
       }

       // Upsert / Insert new documents...
     });
   }
   ```

3. **Admin Panel Client Compatibility:**
   - In `admin-panel/src/services/api.ts`: update `importExcel(file: File, mode: 'append' | 'overwrite' = 'append', onProgress?: ...)` to call `formData.append('mode', mode)`.
   - In `admin-panel/src/components/BulkUploadModal.tsx`: add an Overwrite/Append toggle with a confirmation modal warning that existing data will be replaced.
