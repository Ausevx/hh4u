Implement the complete Chatbot Engine backend for the Healing Hands4U app ecosystem, fulfilling R1 (Vendor-Agnostic AI Service Interfaces), R2 (Query Pipeline & Vector Search), R3 (Consultation Answer Resolution), R4 (Session Logging & Analytics), and full testing & verification.

1. **Phase 0: Survey & Codebase Investigation**

2. **Phase 1: Architecture & Project Definition (PROJECT.md)**

   - Define exact API contracts, directory layout, models, and interfaces.
3. **Phase 2: Implementation & Verification Milestones**
   - Milestone 1: AI Service Abstractions & Mock Providers (R1)
   - Milestone 2: Query Pipeline & Vector Similarity Search (R2)
   - Milestone 3: Consultation Answer Resolution (R3)
   - Milestone 4: Session Logging & Analytics (R4)
   - Milestone 5: E2E Integration & Verification (Jest/Supertest)
4. **Phase 3: Final Verification & Sentinel Hand-off**
   - Challenger & Auditor verification across all requirements.
   - Final report to Sentinel.
